# Рассказы (статьи)

Здесь лежат рассказы для раздела «Рассказы» на сайте. Каждый файл — один рассказ в формате JSON.

**Как добавить рассказ через Prose.io:**

1. Откройте [Prose.io](https://prose.io), выберите репозиторий сайта.
2. Перейдите в папку `articles`.
3. Нажмите «New File», имя файла — латиницей без пробелов (например `moy-rasskaz.json`).
4. Заполните поля в интерфейсе Prose (или вставьте JSON):
   - **title** — заголовок рассказа
   - **image** — путь к картинке (например `./img/foto.jpg`)
   - **content** — текст рассказа
5. Сохраните. После push в GitHub раздел «Рассказы» обновится автоматически (через GitHub Actions).

**Формат файла** (можно править и вручную):

```json
{
  "title": "Заголовок",
  "image": "./img/photo.jpg",
  "content": "Текст рассказа..."
}
```

Конфигурация для Prose.io с полем для картинки задана в корне проекта в `_config.yml`.
