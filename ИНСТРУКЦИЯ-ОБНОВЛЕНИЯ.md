# 🔄 ИНСТРУКЦИЯ: КАК ОБНОВИТЬ СТРАНИЦУ

## 📱 **ЧТО НУЖНО СДЕЛАТЬ:**

### **1. Очистить кэш браузера:**

**Chrome/Edge:**
- Нажмите `Ctrl + Shift + R` (Windows) или `Cmd + Shift + R` (Mac)
- Или: F12 → вкладка Network → галочка "Disable cache" → перезагрузить

**Firefox:**
- Нажмите `Ctrl + Shift + R` (Windows) или `Cmd + Shift + R` (Mac)
- Или: F12 → вкладка Network → галочка "Disable cache" → перезагрузить

**Safari:**
- Нажмите `Cmd + Option + R`
- Или: Разработка → Пустой кэш (Develop → Empty Caches)

### **2. Альтернативный способ:**
- Закройте все вкладки с сайтом
- Откройте новую вкладку
- Введите адрес вручную: `http://localhost:8001`
- Не используйте историю браузера

### **3. Проверка результата:**
1. Откройте сайт
2. Переключите на иврит (HE)
3. Меню должно быть **видно справа**
4. Переключите на русский (RU) 
5. Меню должно быть **видно слева**

---

## 🔍 **ЕСЛИ НЕ ПОМОГАЕТ:**

### **Откройте в режиме инкогнито:**
- Chrome: `Ctrl + Shift + N`
- Firefox: `Ctrl + Shift + P`
- Safari: `Cmd + Shift + N`

### **Или используйте другой браузер:**
- Если не работает в Chrome → попробуйте Firefox
- Если не работает в Firefox → попробуйте Safari

---

## ⚡ **ПРОВЕРКА ОБНОВЛЕНИЙ:**

После очистки кэша проверьте:
- ✅ Меню языков видно на **обоих языках**
- ✅ При переключении язык меняется
- ✅ Позиция меню логичная (слева для русского, справа для иврита)

---

## 🎯 **ГОТОВО!**

После этих шагов сайт должен работать правильно с обоими языками! 🌵
